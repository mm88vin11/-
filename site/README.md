# lllbaza.ru — сайт студии БАЗА

Статический сайт: один HTML + картинки + четыре скрипта. Ни сборщика в
рантайме, ни бэкенда, ни базы — то, что лежит в `dist/`, кладётся в корень
хостинга как есть.

## Сборка

```bash
python3 haze.py     # только если поменялись кадры фона
python3 build.py    # src/ -> dist/
```

`build.py` копирует `src/assets` и `src/vendor` в `dist/`, вставляет в
`index.html` карту ресурсов из `src/resources.json` и больше ничего не делает.

## Что где

| Путь | Что это |
| --- | --- |
| `src/template.html` | вся страница: разметка + логика (класс `Component`) |
| `src/resources.json` | карта `id ресурса -> путь к файлу`, её читает рантайм |
| `src/assets/seqd`, `seqm5`, `seqdc`, `closem5` | кадры ноутбука: раскрытие и закрытие, десктоп и телефон |
| `src/assets/brand` | логотипы |
| `src/assets/haze` | заранее размытые фоны (см. ниже) |
| `src/vendor` | React 18.3.1, React DOM, рантайм шаблонов и рантайм страницы |
| `haze.py` | генерирует `src/assets/haze` из кадров фона |

## Фон

Два слоя фона раньше были полноразмерными кадрами с `filter: blur(72px)` и
`blur(88px)` под бесконечной анимацией — браузер пересчитывал это размытие
каждый кадр, и страница шла на ~2.5 fps. Теперь размытие и цветокоррекция
запечены в картинку 160 px шириной (`haze.py`), а CSS-фильтр убран: тот же
вид, ~30 ms на кадр вместо ~390 ms. Правится через `haze.py`, не через CSS.

## Публикация на reg.ru

1. Собрать: `python3 build.py`.
2. Залить содержимое `dist/` в корень сайта (`public_html`) — файловым
   менеджером панели или по FTP. Структуру папок сохранить.
3. Удалить парковочную страницу хостинга, если она осталась.

PHP и база не нужны — отдаётся как статика.
