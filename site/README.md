# БАЗА — сайт

Одностраничник студии. Девять «вселенных» по скроллу, интерактив в каждой,
заявка уходит в Telegram.

## Сборка

```bash
python3 build/extract.py          # разложить ассеты из старой сборки (один раз)
python3 build/bundle.py --folder  # dist/site/   — то, что деплоим
python3 build/bundle.py           # dist/index.html — всё одним файлом
python3 build/bundle.py --both
```

Исходники — в `src/`, ассеты — в `assets/`, оба билда собираются из них.

**Деплоить нужно папочный билд** (`dist/site/`). Разница не косметическая:

| | папка | один файл |
|---|---|---|
| документ до первой отрисовки | 0.38 МБ | 13.7 МБ |
| кадры ленты | по мере надобности, только свой набор | все 286 внутри документа |
| кэш между заходами | пофайловый | нет, файл целиком |

Одним файлом удобно отправить на просмотр, но у него два врождённых минуса:
base64 добавляет треть к весу каждого бинарника, и внутрь попадают оба набора
кадров — десктопный посетитель тянет ещё и мобильные, которых не увидит.

## Куда уходит заявка

Настраивается в `src/js/03-lead.js`, объект `LEAD`:

- `endpoint` — свой обработчик (CRM / Make / n8n / worker). Получает
  `POST application/json`. **Единственный по-настоящему безопасный путь:** за
  ним токен вообще не приезжает в браузер.
- `tgToken` + `tgChat` — прямая отправка ботом, когда бэкенда нет.

Токен на клиенте не лежит строкой: `TGX` — это XOR с `TGK`, склеиваемый только
в памяти вкладки. Это защищает от сканеров, которые круглосуточно обходят сайты
и ищут в исходниках шаблон `1234567890:AA…`, — но не от человека с консолью.
Если бот умеет только писать в один чат, риск ограничен; всё остальное решает
`endpoint`.

Порядок каналов — endpoint → Telegram HTML → Telegram plain text, первый
успешный останавливает цепочку. Заявка кладётся в очередь `localStorage` **до**
отправки, поэтому закрытая на полуслове вкладка её не теряет: очередь
дошлётся при следующем заходе. Если не принял никто, человеку говорят правду и
дают ссылку «отправить в Telegram сейчас», а не рисуют ложное «отправлено».

Антиспам без капчи: honeypot роняет отправку молча (заполнить скрытое поле
человек не может), а подозрительно быстрое заполнение **не роняет ничего** —
только помечает сообщение. Живая заявка от человека с автозаполнением стоит
дороже, чем пропущенный спам.

## Проверка

```bash
npm i                                # playwright
node build/check.js [--shots]        # 5 вьюпортов: ошибки, кадры, боковой скролл
node build/test-lead.js              # заявка правда уходит и что в ней
node build/test-mobile.js            # зум, мёртвые зоны, прыжки при тапе
```

`check.js` меряет не средний кадр, а долю кадров, вылезших за 33 мс: рывок
чувствуется именно по ним. Браузер берётся предустановленный
(`/opt/pw-browsers/chromium-1194`), скачивать второй не нужно.

`test-lead.js` перехватывает `api.telegram.org` — до боевого бота ничего не
доходит, и токен читать не требуется.

## Структура

```
src/index.html      разметка + слоты <!--@css--> <!--@js--> <!--@res-->
src/css/01-base.css     токены, сброс, шапка, прелоадер
src/css/02-sections.css секции, вселенные, переходы
src/js/00-core.js       один rAF, один scroll-листенер, сцены
    01-audio.js         чиптюн на осцилляторах, ничего не грузится
    02-data.js          весь текст
    03-lead.js          заявки
    04-hero.js          лента ноутбука + поле под курсором
    05-fx.js            прелоадер, клик, бегущая строка
    06-universes.js     фоны
    07/08-sections.js   интерактивы
    10-transitions.js   переходы между вселенными
    11-brief.js         форма
    12-app.js           режиссёр сцены, хром
```

Ядро держит **один** `requestAnimationFrame` и **один** обработчик скролла на
всю страницу. Кадр разделён на фазы: сначала измеряются все прямоугольники,
потом пишутся все стили — иначе каждая секция заставляла бы браузер
пересчитывать раскладку заново. Сцены тикают только рядом с вьюпортом.

## Что стоит знать, прежде чем править

- **Шрифты и токены живут в `:root` в начале `01-base.css`.** Если в CSS-файл
  попадёт литеральный тег `<style>`, сборщик вложит его в свой, браузер
  споткнётся о вложенный тег и выбросит всё после него — вместе с `:root`.
  Сайт при этом не падает, а тихо рендерится в Times New Roman без единого
  токена. Проверяется мгновенно: `getComputedStyle(document.documentElement)
  .getPropertyValue('--f-sans')` не должно быть пустым.
- **Поля ввода — не мельче 16px.** Safari на iOS зумит страницу при фокусе в
  поле с более мелким шрифтом и обратно её не возвращает.
- **`touch-action:none` на крупном блоке — мёртвая зона.** Палец, начавший
  движение на нём, не пролистает страницу. Жест перехватывается по удержанию
  через `preventDefault` в не-пассивном `touchmove`; менять `touch-action` на
  лету бесполезно — браузер решает судьбу жеста в момент его начала.
- **Кадры ленты не растягиваются выше натуральной величины.** Исходник
  1600×901; на широком экране кадр стоит 1:1 по центру, а поле вокруг
  заливается той же плашкой. Снять это ограничение — получить мыло на первом
  же мониторе шире 1600.
