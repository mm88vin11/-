# Fonts

These files are cyrillic + latin `unicode-range` subsets of five Google Fonts
families, vendored so the page makes no third-party request. Each is used under
the **SIL Open Font License 1.1** (https://openfontlicense.org).

| Family | Author | Upstream |
| --- | --- | --- |
| Manrope | Mikhail Sharanda | https://fonts.google.com/specimen/Manrope |
| Unbounded | Gruppo Studio (Nikita Kanarev) | https://fonts.google.com/specimen/Unbounded |
| Pixelify Sans | Stefie Justprince | https://fonts.google.com/specimen/Pixelify+Sans |
| Russo One | Jovanny Lemonad | https://fonts.google.com/specimen/Russo+One |
| JetBrains Mono | JetBrains | https://fonts.google.com/specimen/JetBrains+Mono |

To refresh, re-fetch the `css2` stylesheet for the weights listed in
`assets/css/fonts.css`, keep the `cyrillic` and `latin` blocks, and download the
`.woff2` each one points at.
