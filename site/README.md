# lllbaza.ru — одностраничник

Сайт собирается в один самодостаточный HTML-файл: разметка, стили, шрифты,
логотипы и 132 кадра интро лежат внутри него в base64. Открывается с диска,
без сервера и без сети.

## Из чего собран репозиторий

| Файл | Что это |
| --- | --- |
| `body.html` | Всё, что правится руками: шаблон `<x-dc>`, стили и компонент. |
| `build/01-head-resources.txt` | Копии React в `<head>` — их ждёт загрузчик. |
| `build/99-tail-resources.txt` | Остальной каталог ресурсов, ~19 МБ base64. |
| `build/00-doctype.txt`, `build/zz-close.txt` | Первая и последняя строки документа. |
| `build.sh` | Склеивает всё это обратно в один файл. |

Ресурсы вынесены из `body.html` намеренно: две строки на 19 и 0,2 МБ делали
рабочий файл нередактируемым и нечитаемым в диффах. Правится только
`body.html` — остальное не трогается.

## Сборка

```bash
./site/build.sh                 # → site/dist/index.html
./site/build.sh /path/to/out.html
```

Склейка побайтово обратима: собранный файл из неизменённых частей совпадает
с исходником бит в бит.

## Проверка

`site/dist/` в гит не попадает. Открывается как обычный файл:

```bash
./site/build.sh && xdg-open site/dist/index.html
```
